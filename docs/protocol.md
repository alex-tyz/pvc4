# Протокол обмена

USART6, PC6 TX / PC7 RX, **38400, 8N1**, без управления потоком.
ASCII, команды завершаются LF или CR/CRLF. Ответы завершаются CRLF. Регистр команд несущественен.

| Команда ПК | Ответ |
|---|---|
| `PING` | `PONG COMPASS LSM9DS1` / `LSM9DS0` / `NONE` |
| `GET` | `DATA x y z dir kx ky kz` либо `ERR SENSOR` |
| `SCALE kx ky kz` | `OK SCALE kx ky kz` |
| `STATS` | `STATS uptime_ms frames max_render_ms late display_errors rx_errors max_gap_ms` |

После запуска приходит `HELLO COMPASS FREERTOS`. Исходный клиент ЛР3 принимает HELLO с произвольным описанием.
Каждые 200 мс передается `DATA` или `ERR SENSOR`, независимо от запросов.

`x y z` — целые мГс после применения коэффициентов; `dir` — угол вектора поля от верха платы по часовой стрелке, 0…359°,
либо −1 при неопределенном горизонтальном направлении. Это направление вектора относительно платы, а не географический азимут самой платы.
Коэффициенты целые 0…200, по умолчанию 100. Подтверждение SCALE означает прием настроек; следующий опрос датчика применяет их.
Каждая строка DATA содержит коэффициенты именно своего снимка измерения, поэтому при переключении настроек нет смешения старых значений с новыми коэффициентами.

Ошибки: `ERR RANGE` — коэффициент вне диапазона, включая переполнение числа; `ERR SYNTAX` — неправильные аргументы, слишком длинная или поврежденная строка;
`ERR UNKNOWN` — неизвестная команда. Недопустимая команда не меняет ни одного коэффициента.
Максимум 48 символов до перевода строки. После переполнения RX-очереди остаток потока отбрасывается до следующего разделителя строки.

Строка STATS добавлена в ЛР4 и не изменяет DATA. `frames` учитывает только успешно отправленные полные кадры после начальной инициализации;
`max_render_ms` — максимальное время прохода задачи дисплея, `late` — число несостоявшихся ожиданий очередного периода,
`display_errors` — ошибки обновления или захвата I2C mutex, `rx_errors` — переполнения/ошибки UART,
`max_gap_ms` — максимальный промежуток между успешными кадрами. Все счетчики uint32, с переполнением по модулю 2³².
Средняя частота между двумя ответами: `1000 × Δframes / Δuptime_ms`. Счетчик `00…99` на дисплее увеличивается после успешной отправки кадра.

Пример обмена (пример формата, не протокол реального испытания):

```text
> PING
< PONG COMPASS LSM9DS1
> SCALE 200 100 0
< OK SCALE 200 100 0
< DATA 240 -45 0 101 200 100 0
> SCALE 201 100 100
< ERR RANGE
```
